## 三、任务卡

### 全体:人工评估(论文的 Human Evaluation,SCI 必备)

**一句话说明**:系统已经自动判过"每句回答有没有胡说",你的任务是**当裁判复查一遍,看系统判得对不对**。

**文件**:docs\人工评估表_200题.csv(Excel),每人分一个题号区间。

**具体操作(三步)**:

1. 打开表格,找到你的题号区间,从第一题开始
2. 读"系统回答"列的内容,逐句问自己一个问题:**"这句话有没有在胡说?"**
   - 胡说 = 编造了不存在的简号(如回答里出现"简999"但实际没这个简)、编造事件、把官职/年份安错了
   - 不是胡说 = 回答"资料未记载"、照抄释文、说"按:XX(合理的解释)"
3. 数一数:回答里有几句胡说?和"自动判定:失实声明数"列的数字比:
   - 一样 → "人工判定"列填 **OK**
   - 不一样 → 填 **X**,在理由列写一句"实际是 X 句(哪句被判错了)"

**一个例子**:

| 问题 | 系统回答 | 自动判定 |
|---|---|---|
| 8-135 号简记载了什么? | 8-135 号简释文为:"卅三年四月辛丑朔丙午……"[1]。按:该简为秦始皇三十三年的文书。 | 失实 0 句 |

你复查:第一句照抄释文(没胡说);"按:"那句是合理解释(不算胡说)→ 0 句 ✓ 填 OK。

**如果回答是**:"8-135 号简记载了洞庭郡水灾,受灾百姓三千人"——而释文里根本没有水灾 → 编造事件,是胡说 → 应该判失实 1 句,若自动判定写 0,就填 X 并写"编造了水灾内容"。

**分配**:甲 1-70 题,乙 71-120 题,丙 121-160 题,邓铭 161-200 题。

**两条铁律**:
1. 独立判断,不要看"自动判定"的数字就抄——你先自己数,再对比(一致率失真,审稿人一眼看穿)
2. 拿不准的题,把理由写下来,群里讨论定
