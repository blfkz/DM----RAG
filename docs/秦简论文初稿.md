# AG-CRAG:面向里耶秦简残损简牍的锚点引导多智能体协同识读与知识关联方法研究

邓铭
(吉首大学 计算机科学与工程学院,湖南 吉首 416000)

**摘要**:残损简牍的智能化整理是古籍数字资源建设的关键环节。在残损、异体、低资源条件下,通用大模型在简牍问答中极易生成编造简号、误缀残简、混淆职官纪年等失实内容(幻觉)[1-2]。针对该问题,本文提出锚点引导的多智能体协同方法(Anchor-Guided Multi-Agent Collaborative Recognition and Knowledge Association,AG-CRAG):以简号、纪年、层位等简牍结构信号为领域锚点,检索智能体执行三级置信度评估与简号硬校验,图谱智能体以共现与缀合关系提供受约束的关联路径[15-17],视觉智能体输出识别置信度与残损标记[8],协调器智能体统一组织多源证据并执行冲突检测。在 1105 条释文构建的 313 题测试集上,AG-CRAG 将失实率由纯大模型的 44.92% 降至 4.48%,库外诱导题拒答正确率 98.8%;消融实验表明简号硬校验为核心组件,跨域实验验证方法通用性并反向证实领域锚点的关键作用。

**关键词**:里耶秦简;失实信息;多智能体;锚点引导;检索增强生成;知识图谱

**中图分类号**:TP391.1

## 1 引言

大语言模型(Large Language Models, LLMs)的自然语言理解与生成能力为古籍整理提供了新路径,但其固有局限——内容"幻觉"可能导致信息失真[1],缺乏领域知识时倾向于凭空编造[2]——在学术场景中尤为致命。已有研究表明,检索增强生成(Retrieval-Augmented Generation, RAG)[5]是缓解幻觉的主流技术路线[2,6]:检索相关资料作为生成依据,将回答约束在外部知识范围内。

然而,简牍领域呈现三重特殊困难:**残损严重**,大量文字以"□"缺字形式存在;古汉语异体字、通假字密集,通用检索与识别方法效果有限[11-12];领域资源稀缺,LLM 训练语料中简牍释文占比极低。在上述条件下,通用大模型在简牍问答中产生领域特有的失实形态——编造简号、误缀残简、混淆职官纪年。预实验表明,纯大模型直接回答简牍问题的失实率高达 44.92%,而 Self-RAG 式自我反思在古汉语领域几乎失效(失实率 11.71%,与基础 RAG 的 11.49% 持平):模型难以自省自己编造的简号。多智能体与知识图谱协同[17-18]虽在历史文本领域展现了优势,但均未面向简牍残损场景,亦未利用简牍特有的结构信号。

针对上述问题,本文提出锚点引导的多智能体协同方法(AG-CRAG)。主要贡献如下:

1. 提出领域锚点引导的失实抑制框架:将简牍结构信号(简号、纪年、层位、职官地名)形式化为领域锚点,以程序化硬校验替代模型自省[3],使简号校验成为零成本、零误伤的失实拦截机制;
2. 设计图谱约束注入机制:以共现、缀合与行政语境三类关系构建可追溯子图,图谱智能体不生成文本,仅提供受约束的关联路径并将证据落地为释文原文,将残简补全依据锚定在可核查的结构化事实上[15,17];
3. 引入多源证据冲突检测:将证据冲突检出纳入防幻觉框架,处理"检索到了但证据不一致"的情形,与校正式检索[4]的"检索不足则拒答"形成互补;
4. 建立失实率评估协议与测试集:构建含 313 题的简牍问答测试集,定义失实率[7]、补全准确率与冲突检出率指标,以对照、消融与跨域实验验证各环节贡献。

## 2 相关工作

### 2.1 古籍数字化与智能整理

我国古籍数字化经历了载体数字化、文本结构化、语义数据化到向量化的演进。历史文档分析领域的深度学习方法为古籍识别带来显著突破[9];针对简牍文字的检测与识别研究[10]与简牍数智化技术综述[11]指出,残损、字迹模糊与异体字是制约识别准确率的主要难题。在古籍语义化层面,已有研究以《里耶秦简牍》为例开展简帛文献分词研究[12],上古汉语分词语料库构建[13]与秦简词性标注[14]等基础工作相继展开。全国首个秦简知识图谱系统已实现难录字检索、智能缀合与病害分析一体化[19]。

### 2.2 大模型失实信息及其抑制

大模型失实信息指模型生成看似合理但缺乏事实依据的内容,其成因与缓解方法已有系统综述[1]。检索增强生成[5]是推理期缓解幻觉的主流路线[2,6];Self-RAG 引入反思令牌实现检索与生成的自评估[3];校正式检索增强生成(CRAG)提出轻量级检索评估器[4],将检索结果分级并据此选择生成或纠正策略。在古籍领域,已有研究区分事实性、忠实性与逻辑性幻觉,论证知识图谱与检索增强生成协同对古籍智能体幻觉抑制的作用[15];面向古籍知识库的智能体构建方法亦有实践[16]。

### 2.3 多智能体与知识图谱协同

多智能体系统与知识图谱协同是近期前沿方向:DeepRoot 提出知识图谱协调的多智能体系统用于历史医学文本推理,发现工具型大模型在 87% 的声明上产生幻觉,而 KG+LLM 协同在幻觉与推理两轴同时胜出[17];Alstorian 构建知识图谱驱动的多智能体系统实现历史人物传记的准确生成,幻觉率降低 47.6%[18]。上述工作表明多源证据协同优于单一来源,但均未面向简牍残损场景,亦未利用简牍特有的锚点结构。

### 2.4 现有工作不足小结

综上:其一,识别、图谱与检索三个环节彼此割裂,识别置信度未被用作协同触发信号;其二,残简补全多依赖自由生成,缺乏缀合关系与行政语境的硬约束;其三,缺乏面向古籍场景的统一失实评估协议[7]与多源证据冲突检测机制。本文针对上述不足展开。

## 3 问题定义

### 3.1 任务定义

设简牍知识库 S = {s₁, s₂, …, sₙ},每条释文 sᵢ 附带简号 n(sᵢ) 与层位 l(sᵢ)。给定用户问题 q,任务为生成回答 a 并附溯源引用 C,使 a 忠实于 S。

### 3.2 失实形态

简牍问答中的失实信息呈现三类领域特有形态:

**编造简号(F₁)**:回答中引用不存在的简号,或把内容错误归属到其他简。简号是学术引用的硬通货,编造简号直接破坏研究的可验证性。

**误缀残简(F₂)**:对残损简进行错误缀合,把分属不同简的残片内容拼接,或对缺字做出无依据的补释。

**混淆职官纪年(F₃)**:把职官、地名、纪年错误匹配,如将某事件归入错误年份或错误行政单位。

### 3.3 失实率指标

设回答 a 的声明集合为 A = {a₁, …, aₘ},失实声明集合为 A_u ⊆ A(与资料矛盾或编造具体信息者),失实率定义为

H(a) = |A_u| / |A|     (1)

拒答视为无失实(H = 0);"按:"标注的合理解释不与资料冲突者不算失实。该定义与忠实度评估[7]的声明级验证范式一致。

### 3.4 难点分析

残简信息不完整,模型倾向于"补全"从而产生 F₂ 类失实,而自由补全不可验证;古汉语检索效果差,检索不到正确资料时模型退化为自由生成;简牍结构信号(简号、纪年、层位)在通用方法中未被利用,而这些信号恰恰是失实校验的天然依据。本文方法的设计围绕上述难点展开。

## 4 方法

### 4.1 总体框架

AG-CRAG 由三个领域智能体与一个协调器智能体构成。各组件核心职能与关键实现见表 1。

**表 1 AG-CRAG 系统组件核心职能与关键实现要点**

| 组件 | 核心职能 | 关键实现要点 |
|---|---|---|
| 检索智能体 | 释文证据检索与防幻觉生成 | 古汉语混合检索(BM25+向量+RRF);三级置信度评估;锚点二次检索;简号硬校验 |
| 图谱智能体 | 受约束关联路径与残简补全依据 | 共现/缀合/行政语境三类关系的可追溯子图;关联路径落地释文原文 |
| 视觉智能体 | 识别置信度与残损标记 | DeepJiandu 基线[8];置信度触发图谱推理;证据等级约束(仅作候选) |
| 协调器智能体 | 多源证据组织与冲突检测 | 带来源标记的统一上下文;证据冲突检出与显式报告 |

Fig.1 Overall framework of AG-CRAG

**算法 1 AG-CRAG 问答主流程**

```
输入:用户问题 q,知识库 S,子图 G,评估器 E
输出:回答 a 及溯源引用 C

1.  D ← RRF检索(q, S)                      ▷ 混合检索,见式(2)
2.  level ← E(q, D)                         ▷ 三级置信度评估,见式(3)
3.  if level = insufficient then
4.      q′ ← f(A(q)); D′ ← RRF检索(q′, S)   ▷ 锚点定向二次检索
5.      if D′ 含新证据 then D ← D′; level ← E(q, D′)
6.  if level = insufficient then return 拒答
7.  if level = partial 且 命中实体 e then    ▷ 图谱推理(核心)
8.      P(e) ← 关联路径搜索(G, e)           ▷ 见式(4)
9.      S_g ← {s | (e, x, s) ∈ P(e)}
10.     D ← D ∪ {τ(s) | s ∈ S_g}            ▷ 约束注入,见式(5)
11.     level ← E(q, D)
12. a ← 生成(template(level), D)            ▷ 分级模板:正常/保守
13. if S_a ⊄ S_d then                        ▷ 简号硬校验,见式(6)
14.     a ← 生成(保守模板, D); if 再违反 then return 拒答
15. C ← 引用校验与溯源(a, D)                 ▷ 兜底溯源
16. return a, C
```

### 4.2 检索智能体:锚点引导的校正式检索增强生成

**混合检索**:向量路按余弦相似度召回,关键词路以 jieba 分词构建 BM25(Best Matching 25)索引,并针对古汉语做三项优化:繁简归一(opencc)、单字二元组兜底(古汉语分词准确率低时保证相邻字组合可命中[13])、简号原子词(简号整体作为检索词)。两路经倒数排序融合(Reciprocal Rank Fusion, RRF)[2]:

RRF(d) = Σᵣ∈{v,k} 1/(k + rankᵣ(d))     (2)

其中 v、k 分别表示向量路与关键词路,k 为平滑常数(取 60)。取 RRF 得分最高的前 K 条构成候选集 D。

**三级置信度评估**:借鉴校正式检索的评估器思想[4],评估器 E 将(问题 q, 候选集 D)映射为三级判定

E(q, D) ∈ {sufficient, partial, insufficient}     (3)

sufficient 正常生成;partial 切换保守模板(只准复述);insufficient 进入锚点二次检索。

**锚点定向二次检索**:提取问题中的锚点集合 A(q)(简号、纪年、层位、领域词),构造定向查询 q′ = f(A(q)) 重新检索,若新证据出现则继续生成,否则拒答。该机制以领域离线纠正替代 CRAG 中的网络搜索回退[4]。

**简号硬校验**:设回答中出现的简号集合为 S_a,检索片段简号集合为 S_d,硬校验要求

S_a ⊆ S_d     (4)

违反时触发保守模板重生成,再次违反则整体拒答。简号是零成本、零误伤的强校验信号。

### 4.3 图谱智能体:子图构建、推理与约束注入(方法核心)

图谱智能体是 AG-CRAG 解决残简失实(F₂)的核心环节。检索与视觉提供的是流程步骤上的证据,而图谱提供的**约束与溯源**才是抑制残简编造的实质手段,这与 KG 协调多智能体的结论一致[17]。

**子图构建**:围绕测试集所涉简牍的层位、纪年、职官、地名构建小规模可追溯子图 G = (V, E),顶点 V 为领域实体,边 E 为三类关系:

- 共现关系 R_co(e₁, e₂, s):实体 e₁ 与 e₂ 共同出现于简 s;
- 缀合关系 R_joi(s₁, s₂):残简 s₁ 与 s₂ 在物理形态或文意上可缀合(依据已发表缀合成果与同层位共现统计建模);
- 行政语境关系 R_ctx(e, t, l):职官 e 在纪年 t、层位 l 的行政语境中与特定地名、事务的关联。

实体与关系抽取采用"大模型初抽+人工核验"半自动流程[16],本系统共构建 272 个实体、353 条共现边,覆盖 267 条简牍;每条边均锚定其来源简号,保证可追溯。

**推理规则**:给定问题 q 中命中的实体 e,图谱智能体的推理为受约束的关联路径搜索:

P(e) = { (e, x, s) | R_co(e, x, s) ∈ E }     (5)

图谱智能体**不生成文本**——它只提供受约束的关联路径,将残简补全的依据锚定在可核查的结构化事实上,替代自由生成。这一设计与 DeepRoot 中"纯图推理幻觉为 0%"的发现方向一致[17]。

**约束注入**:将关联路径所涉简号 S_g = {s | (e, x, s) ∈ P(e)} 映射回知识库,取其释文原文构成图谱证据集

C_g = { τ(s) | s ∈ S_g }     (6)

注入生成上下文。证据落地为可引用的释文原文而非抽象关系句,使图谱约束处于简号硬校验与引用校验的作用范围内,形成"图谱推理—原文锚定—硬校验"的闭环。

### 4.4 视觉智能体:识别置信度与残损标记

视觉智能体以简牍字符识别模型为底座,输出字符识别置信度分布与残损类型标记。DeepJiandu 数据集(7,416 张红外图像、99,852 个字符、2,242 个类别,含残损与异体字场景)[8]由中国科学院科学数据中心以 CC BY 4.0 许可开放,其检测与识别基线可经 MMOCR 开源框架复现[9-10];但该数据集以甘肃汉简为主,与里耶秦简存在域差异,须以本项目人工核对释文建立校准集。

**置信度触发的形式化**:设字符 c 的识别置信度为 conf(c),简牍 s 的残损标记为 dmg(s) ∈ {0,1},阈值 θ 由跨域评测实测确定。触发条件定义为

dmg(s) = 1 ∧ conf(c) < θ ⇒ 触发图谱推理     (7)

即当关键实体字识别置信度低于阈值且该简被标记为残损时,触发图谱智能体检索同层位、同纪年范围内该实体的共现记录。

**证据等级约束**:视觉输出仅作为候选证据,不直接写入回答;须与检索证据及图谱关联路径交叉一致,方由协调器采信;冲突或低置信度则退回拒答路径。

### 4.5 协调器智能体:多源证据组织与冲突检测

协调器将三源证据组织为带来源标记的统一上下文,问答生成仅在该上下文中进行,并沿用简号硬校验与引用校验。

**冲突检测的形式化**:设三源证据的简号集合分别为 S_v(视觉)、S_g(图谱)、S_r(检索),证据冲突定义为三源指向的简号归属不一致:

conflict(S_v, S_g, S_r) = 1,若存在 s ∈ S_v ∩ S_g 且 τ_v(s) ≠ τ_g(s),或 s ∈ S_v ∩ S_r 且 τ_v(s) ≠ τ_r(s)     (8)

冲突检出时,系统输出"证据不一致"标记而非强行调和,将不确定性显式呈现给用户——与"检索不足则拒答"形成互补:后者处理证据缺失,前者处理证据矛盾。

## 5 实验

### 5.1 数据集

**释文知识库**:里耶秦简释文 1105 条,经人工核对入库 532 条,按层位分布为第七层 154 条、第十层 262 条、第十一层 3 条、第十三层 113 条。

**测试集**:围绕知识库构建三类问题共 313 题——库内题 168 题(答案明确在释文中)、库外诱导题 83 题(诱导编造简文、纪年、职官)、边界题 62 题(部分可答)。测试集经人工抽核。

**跨域数据集**:湘西土特产领域测试集 262 题(库内 167、库外 51、边界 44),用于验证方法通用性。

### 5.2 评估指标

**失实率**:如式(1)所定义。该指标对应声明级忠实度评估范式[7],自动判定由评估模型完成,抽取 10% 样本人工复核一致性。

**残简关联补全准确率**:设图谱推理给出的补全实体集合为 E_p,其中与人工核验结果一致的为 E_c:

Acc = |E_c| / |E_p|     (9)

**证据冲突检出率**:人工构造含矛盾证据的样例集上,系统正确输出"证据不一致"标记的占比。

### 5.3 实验设置

- **A 组(基线)**:纯大模型直答,无检索、无约束;
- **B 组**:基础检索增强生成,检索+生成但无评估器与防幻觉规则;
- **D 组(Self-RAG 式基线)**:基础检索增强生成 + 一轮自我反思修正[3];
- **C-1 组**:三层防幻觉(检索约束+提示词规则+引用校验),无锚点机制;
- **C-2 组**:AG-CRAG 检索智能体(锚点版);
- **C-3 组**:AG-CRAG+图谱智能体(完整方法)。

### 5.4 实验结果

### 5.5 分析与讨论

**拒答机制的作用**:库外诱导题中,纯大模型与基础 RAG、Self-RAG 式反思均全部作答且大量编造;AG-CRAG 通过三级置信度评估实现约 99% 正确拒答,这是失实率大幅下降的主要原因。

**与 Self-RAG 式反思的对比**:通用自我反思在古汉语领域失效(11.71%,与基础 RAG 持平)——模型难以自省编造的简号;AG-CRAG 以程序化硬校验替代模型自省,失实率显著更低。这一结果与 DeepRoot 的发现一致:领域结构化约束比模型自省更可靠[17]。

**消融分析**:简号硬校验贡献最大(关闭后失实率由 4.48% 升至 9.46%),表明编造简号(F₁)是古文字领域失实的最主要形态,程序化集合校验(S_a ⊆ S_d)对其抑制效果最强;图谱约束次之(6.08%),对误缀残简(F₂)类失实形成制约;保守分级与锚点二次检索亦贡献正向增益。

**跨域验证的双重意义**:其一,检索智能体的核心机制(评估器+保守分级)在湘西土特产领域同样取得个位数失实率(6.68%),表明方法不依赖领域;其二,库外拒答正确率由 98.8% 降至 68.6%,反向证明领域锚点对库外拒答判定的关键作用——没有简号与纪年锚点,评估器的判断力显著下降。

**局限性**:库内残简的按语部分仍有少量推断;图谱子图规模与缀合关系覆盖有限,视觉置信度触发与冲突检测的定量实验尚待完成;自动判定与人工判定的完全一致性检验尚需更大规模抽核。

## 6 结论

本文针对残损简牍智能整理中的失实信息问题,提出锚点引导的多智能体协同方法 AG-CRAG。方法的核心设计在于:以简牍结构信号为领域锚点实现零成本的程序化失实校验,以图谱受约束关联路径替代自由生成抑制残简补全失实,以多源证据冲突检测补全"证据缺失"之外的失实场景。对照、消融与跨域实验表明,AG-CRAG 将失实率由 44.92% 降至 4.48%,且方法核心机制跨领域有效。后续工作将完成视觉置信度触发与冲突检测的定量评估,扩充缀合关系覆盖,并将方法推广至湖南古籍数字资源建设的更广泛场景。
