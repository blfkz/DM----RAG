# 第 1 章 项目背景

## 1.1 传承红色基因

湘西土家族苗族自治州是一片红色热土。土地革命时期,红二、红六军团在这里创建湘鄂川黔革命根据地,贺龙、任弼时等老一辈革命家转战武陵山区,土家苗寨的乡亲们用腊肉、糍粑、炒米支援红军——**湘西的特产,自古就带着"拥军支前"的红色记忆**。

2013 年,习近平总书记来到湘西花垣县十八洞村考察,首次提出"精准扶贫"重要理念,湘西自此成为**中国脱贫攻坚伟大实践的首倡地**。今天,十八洞村的猕猴桃、保靖黄金茶、永顺莓茶等湘西特产走出大山,成为乡村振兴的产业名片——但"走出去"的最后一公里,仍卡在大量小店的"叫卖能力"上。

我们作为吉首大学的学生,就学习生活在这片红色土地上。用所学的技术为湘西特产小店做一件实实在在的事,就是我们对红色基因最好的传承。

## 1.2 基本情况:湘西有好物,小店有难处

湘西地处武陵山区腹地,独特的气候与生态孕育了腊肉、猕猴桃、黄金茶、莓茶、姜糖、糍粑等一批品质出众的土特产。近年来,随着直播与电商进村,越来越多的土特产小店尝试线上销售,把"山里的好东西"卖向全国。

然而,湘西特产电商的经营者大多是**个体小店、家庭作坊、合作社**:一人身兼采购、加工、上架、发货、客服数职。线上生意与线下不同——顾客看不见实物,下单前必然要问:**"这腊肉怎么保存?""黄金茶是明前还是明后?""猕猴桃发到北方会不会坏?"** 一问一答之间,信任才建立,订单才成交。

**核心矛盾**:小店需要"随时在线、懂得自家商品、几乎不花钱"的客服,而市面上没有这样的产品。

## 1.3 政策支持

本项目契合多项国家政策导向:

1. **乡村振兴战略**:2026 年是"十五五"规划开局之年,巩固拓展脱贫攻坚成果、全面推进乡村振兴仍是国之大者;
2. **数字乡村建设**:鼓励数字技术下沉县域,赋能小微经营主体;
3. **"人工智能+"行动**:2025 年起国家部署"人工智能+"行动,推动 AI 在各行业落地——AI 进乡村、AI 助农正是最受鼓励的方向之一;
4. **青年红色筑梦之旅**:本赛事红旅赛道正是为"青年学子扎根中国大地、服务乡村振兴"搭建的平台。

# 第 2 章 市场分析

## 2.1 中小电商商家的客服痛点(行业现状)

中小电商商家普遍缺乏专职客服能力:**咨询高峰顾此失彼、深夜咨询无人应答、重复问题反复消耗人力**。市面上的智能客服产品存在两个明显问题:**一是贵**——成熟 SaaS 按坐席收费,小商家用不起;**二是"不懂货"**——通用客服机器人靠预设问答库,答不出"这家的腊肉到底怎么熏的"这类具体问题。而 RAG 技术的特点恰恰是"基于商家自己的资料回答",精准对应这一缺口。

## 2.2 湘西土特产电商的需求(目标市场)

湘西土特产电商具有三个适合本项目切入的特点:

1. **产品有故事、有讲究**:土特产的储存、食用、产地、季节知识丰富,顾客咨询频率高、内容专业——正是 RAG 知识库擅长的场景;
2. **商家分散且规模小**:大量小店、合作社、农户网店分散在县域乡镇,无力负担专业客服;
3. **信任是成交关键**:土特产顾客对"产地正宗、食用安全"极为在意,AI 答案附引用原文,反而比人工回复更显专业可信。

## 2.3 竞品分析

| 竞品类型 | 代表 | 不足 |
|---|---|---|
| 通用智能客服 SaaS | 大型客服云平台 | 按坐席收费,小店用不起;预设问答库,不懂具体商品 |
| 人工客服外包 | 客服外包公司 | 月费数千元,小店难以承受 |
| 电商平台内置机器人 | 各平台自带 | 只能答平台模板问题,无法基于商家资料 |

**本项目的差异化**:①轻量——网页即用,零技术门槛;②本地化——专为土特产小店设计;③可信——答案带引用、不瞎编,这恰是通用客服机器人做不到的。

## 2.4 目标客户群

1. **特产小店/家庭作坊**:湘西州及周边县域的土特产网店经营者(第一优先级);
2. **合作社与农户**:规模化特产生产者,希望直接对客;
3. **文旅场景**:游客扫码了解特产——红色旅游景点(十八洞村、塔卧旧址等)周边特产摊位天然适配。

## 2.5 可行性分析

**政策可行性**:见 1.3,多层面政策鼓励;
**技术可行性**:项目技术原型已全部开发完成并开源(见第 3 章),60 项单元测试与 100 人并发压测均已通过,技术风险已基本消化;
**落地可行性**:吉首大学地处湘西州首府,团队可低成本触达周边特产商家,具备"家门口落地"的天然条件。

# 第 3 章 产品与技术方案

## 3.1 产品形态:一端上传,一端提问

**店主端(资料上传)**:店主把自家特产的产品说明、储存方法、食用指南、常见问题等资料(支持 PDF、Word、Excel 等 6 种格式)上传到系统,即完成"训练"——无需任何技术基础,全程网页操作。

**顾客端(扫码提问)**:顾客扫描小店提供的二维码,像发微信一样用大白话提问("这个腊肉放冰箱能放多久?"),AI 基于店主上传的真实资料即时作答,并展示回答所依据的原文片段。

## 3.2 现有基础:通用电商 RAG 原型(已完成并开源)

项目已完成通用电商领域的 RAG 智能问答原型,核心能力如下:

| 能力 | 说明 | 验证数据 |
|---|---|---|
| 知识入库 | 6 种格式文档解析、中文分块、云端向量化 | 10 类 39 份演示文档全部入库 |
| 混合检索 | 向量 + 关键词(BM25)双路召回,RRF 融合 | 单次检索约 0.16 秒 |
| 防幻觉 | 只依据检索资料作答,答案标注 [n] 引用;模型漏标时自动溯源兜底 | 知识库没有的内容明确回答"没有找到" |
| 多用户体系 | 注册登录、多会话、历史找回、权限隔离 | — |
| 性能 | 自研压测工具实测 100 人并发 | 成功率 99%,平均响应 3.47 秒 |
| 质量 | 60 项单元测试 | 全部通过 |

代码已在 **GitHub、Gitee 双平台开源**(github.com/blfkz/DM----RAG;gitee.com/blfkz/langchain-rag),技术方案公开透明。

## 3.3 核心技术:三层防幻觉机制

大模型直接回答容易"一本正经地胡说八道"。本项目用三层机制保证每个答案可信:

1. **检索层**:模型只能看到从知识库检索出的真实片段;
2. **提示词层**:硬约束"只依据资料作答,资料不足必须明确说找不到";参考资料预编号,让模型"抄编号"做引用;
3. **引用层**:解析校验编号;模型漏标时按句子相似度自动溯源兜底——**保证任何回答都有原文依据**。

## 3.4 开发方式(如实说明)

我作为项目第一完成人,主导完成了**需求设计、RAG 架构设计与技术选型**(如为什么采用混合检索、为什么选择云端大模型 API 而非本地部署、防幻觉的三层机制设计等关键决策),开发过程中使用 AI 工具辅助代码实现与调试。

## 3.5 下一阶段开发计划:从"通用电商"到"湘西特产"

1. **湘西特产知识库模板**:针对腊肉、黄金茶、猕猴桃、莓茶等特产品类,设计标准化的资料模板(产品介绍/储存/食用/物流/售后),让店主"照着填"即可完成知识库搭建;
2. **店主端界面改造**:面向零技术基础的小店店主,极简化上传与维护流程;
3. **顾客端轻量化**:扫码即问,适配手机浏览器,降低顾客使用门槛。

# 第 5 章 财务分析(创意阶段规划)

> 如实说明:本项目处于创意计划阶段,**目前无任何收入、无付费客户、无公司实体**。以下为启动与运营的规划设想。

## 5.1 启动资金规划(设想)

| 用途 | 规划金额 | 说明 |
|---|---|---|
| 云端 AI 服务费用 | 低至数百元/年 | 试点期咨询量有限,按量计费成本可控(实测 600 次问答约 2 元) |
| 服务器/域名 | 约 1000 元/年 | 学生优惠云服务器 |
| 宣传物料 | 约 500 元 | 二维码立牌、单页 |
| 合计 | 约 2000 元以内 | 轻资产启动,主要成本为零(技术已自研完成) |

**本项目的成本结构优势**:核心系统已由团队自主开发完成,无需研发投入;按量付费的云端模式让成本与使用量线性挂钩,适合公益起步。

## 5.2 收入模式设想(未来规划)

1. **公益起步**:试点期对签约小店免费开放,换取真实使用数据与案例;
2. **小额订阅**:试点成熟后,向商家收取低年费(定价目标:低于人工客服成本的 1/10);
3. **延伸服务**:带货咨询、文旅导览问答等场景合作;
4. **政企合作**:申报乡村振兴相关项目,争取县域商务部门、供销社资源支持。
